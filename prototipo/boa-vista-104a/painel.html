9 · E-mails ao gerar a proposta desenho para o dev

Quando o cliente gera a proposta, aceitando ou não o contrato, cada participante ligado aqui recebe um e-mail com o conteúdo do seu papel. Esta página ainda não envia e-mail: ela mostra como vai funcionar no sistema final.

Para o desenvolvimento
  1. Gatilho: os botões "Enviar proposta" e "Seguir para contrato" da página do cliente. Os dois geram a proposta e disparam o evento proposta_gerada, aceitando ou não o contrato.
  2. O backend cria uma linha em notificacao_proposta para cada destinatário ligado e envia a partir dessa fila. Um destinatário por papel por evento, para reenvio não duplicar.
  3. O indicador só recebe o aviso mínimo, sem nome, WhatsApp ou valores do cliente. A regra também fica travada no banco.
  4. Aqui os e-mails são cadastrados por unidade. No sistema final vêm do cadastro dos participantes de cada negociação.
  5. Pendente: provedor de e-mail e remetente; cópia para o cliente; imobiliária recebe a proposta completa ou só o resumo.
